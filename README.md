# Coffee Shop Sales Analysis Dashboard

## Project Overview
This project analyzes coffee shop sales data to identify
trends and generate actionable business insights.

## Objectives
- Analyze sales by day and hour.
- Identify peak sales periods.
- Compare monthly revenue.
- Evaluate store performance.
- Calculate average order value.
- Identify best-selling products.
- Analyze product categories and types.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Data Visualization

## Key Findings
- Total sales revenue: 698,812.33
- Total transactions: 149,116
- Highest-revenue month: June
- Highest-revenue store: Hell's Kitchen
- Leading product category: Coffee

## Project Files
- `Coffee Sales Dashboard.xlsx` — Excel workbook
- `Coffee Shop Sales Analysis.pdf` — Analysis report
- `Coffee sales.png` — Dashboard screenshot

## Conclusion
The project provides insights into sales trends, store
performance, and product demand to support business decisions.
